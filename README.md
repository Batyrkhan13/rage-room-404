# RAGE ROOM 404 — сайт

Главная страница комнаты ярости RAGE ROOM 404 в Алматы.
Статический сайт без сборки: `index.html`, `styles.css`, `script.js`, `assets/`.

## Как посмотреть локально

Откройте `index.html` в браузере или запустите любой статический сервер в папке проекта.

## Что заполнить перед запуском

На странице все незаполненные данные выделены жёлтым и записаны в квадратных скобках: `[ЦЕНА]`, `[АДРЕС]` и т.д.

- Цены, тарифы и состав пакетов
- Длительность сеанса, предметы, инструменты, экипировка
- Правила безопасности и возрастные ограничения, ответы на вопросы
- Адрес, часы работы, телефон, WhatsApp, Instagram, карта
- Реальные отзывы (или удалить блок)
- Политика обработки данных, юр. лицо / ИП, БИН
- Номер WhatsApp для заявок — `BOOKING_CONFIG` в начале `script.js`

## Видео

- `assets/video/session.mp4` и петли `loop-*.mp4` — собственные съёмки RAGE ROOM 404.
- `assets/video/qangybas-reel.mp4` — репортаж автора @qangybas.almaty. Используется с указанием автора; перед публикацией нужно разрешение автора.
